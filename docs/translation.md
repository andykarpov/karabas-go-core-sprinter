# Перевод AHDL → Verilog: правила и проверка (Ф1.1)

Основа — AHDL 3.03a (`upstream/tt-sp2000-acex`); модули в `src/rtl/acex/` (`sp_<модуль>.v`), таблицы MIF → `src/rtl/acex/mif/*.hex` (`tools/mif.py hex`). Отличия версий — `docs/versions.md`.

## Правила

Один такт `CLK`, разрешение `CE` = передний фронт исходных 42 МГц (на плате `CLK` = 84 МГц, `CE` через такт; в тестах модулей `CLK` = 42 МГц, `CE` = 1). Для отрицательного фронта 42 МГц — второе разрешение (`CE_N`), где он нужен.

1. **Порядок аргументов AHDL**: `DFF(d, clk, clrn, prn)`, `DFFE(d, clk, clrn, prn, ena)`. `DFF(x, CLK42, , y)` — это **preset** от `y`, не clear (ошибка, найденная на KBD: INT и F12).
2. **Триггер на CLK42** → регистр, обновляемый при `CE`.
3. **Триггер на производном такте** (выход другого триггера, счётчик, `!KB_CT2`) → событие: передний фронт источника, вычисленный по его *следующему* значению в том же `CE`, где источник меняется. Так сохраняется порядок «пульсации» оригинала, задержки нет. Данные такого триггера: фронт «пульсации» приходит **после** фронта CLK42, поэтому регистры на CLK42 он видит уже **новыми** — в событии берутся их следующие значения (AY: `AY_CH_A..C` по `AY_CCC7` защёлкивают новые `AY_DQ1..3`); входы модуля — текущими. Сигнал верхнего уровня, который служит тактом в модуле (`DFF(CTH5)`, стробы портов), приходит событием `*_EV` — высоким в том `CE`, где этот регистр растёт.
4. **Триггер на внешнем такте** (вход модуля, например `CLK_K`) → выделитель фронта по входу; наш модуль реагирует на `CE` позже, чем микросхема (она — внутри такта). В сравнительном тесте такой вход подаётся эталону на такт позже — тогда все пути через него совпадают.
5. **Асинхронные `clrn` / `prn`** → действующее значение `*_e` (принудительное, пока вход активен); в `CE`, где вход активен **до фронта**, регистр получает принудительное значение — сброс / установка побеждает фронт (ошибка, найденная на KBD: счётчик строк `KB_MA` на такт впереди). Активны оба — побеждает `clrn` (так в эталоне: MAX `CNF_OFF`).
9. **RS-защёлки на `EXP` / `LCELL`** (перекрёстные `EXP(a & b)`; `EXP` у MAX+plus II — инвертор) → действующее значение из входов установки / сброса и хранимого состояния, без задержки (MAX: 312 / 320 строк, выбор HDD).
6. **`lpm_ram_dq` / `lpm_ram_dp` с `inclock` = CLK42, выход без регистра** → блочная память с регистровым адресом (синхронное чтение), write-first.
7. **`LCELL` / `EXP` как задержки** → убираются (задержка — свойство микросхемы, у нас синхронно); где оригинал на неё опирается — отмечается в коде.
8. Начальные значения триггеров = 0 (ACEX при включении обнуляет). У сетевого списка Quartus регистр с `prn` хранится инверсно, его начальный выход = 1: сравнение начинается после первых тактов.

## Проверка

`src/sim/eq/run_eq.sh [модуль ...]` — наш модуль против эталонного сетевого списка AHDL (`docs/refsim.md`) на одних и тех же входах; выходы сравниваются в каждом такте (по спаду, оба устоялись). Ошибка = расхождение при задержке 0; расхождения при задержках 1..3 печатаются для диагностики. Выход, который ни разу не переключился, — слабый тест (печатается).

## Верх ACEX (`sp_acex.v`)

- Выводы Z80 — в двух копиях: текущие (`M1_N` …) и `*_NX` (значение сразу после этого `CE`); все события (`IOWR`, `IORD`, спады / фронты `/MR`, `*_EV` подмодулей) верх строит сам. В ядре T80 работает по `CE_N`, его выходы — это `*_NX`, регистр по `CE` даёт выводы.
- Двунаправленные шины разделены на `_I` / `_O` / `_OE`; `_I` без драйвера держит последнее значение (оригинал защёлкивает код команды по фронту `/MR` после отпускания шины).
- `TEST_SWITCH = TFF(…, KB_F12, , /RESET)` — четвёртый аргумент это **preset**: при включении и сбросе 1 (то же правило 1).
- Гонка REFRESH в DCP: `RFT` тактуется `CT4`, предустанавливается `RFC`, оба меняются в одном фронте. Сетевой список целиком решает её так: активный до фронта `RFC` поглощает такт — `sp_dcp` параметр `REFRESH_REG = 1` (верх передаёт 1; отдельный `tb_eq_dcp` — 0, как раньше).
- **Открыто:** регистры подмодулей с preset у эталона стартуют с 1 (`KB_CT` = 7, `KB_F12`, `KB_RESET`, `INT`, `KDD[7:6]`, `KBD[]` = 3F, `ACC_GO` / `ACC_END` / `ACC_BLK`, `CTH` = 50, `CTV` = 290), у наших — с 0; стенд ставит их на 1 пс. Для ядра — перенести в начальные значения / сброс модулей (иначе `KB_RESET` = 0 держит `/RESET` четыре строки).
